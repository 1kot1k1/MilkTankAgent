# MilkTankAgent

## Назначение

Приложение предназначено для опроса весовых терминалов по протоколу Modbus,
формирования JSON-пакетов и передачи данных на сервер.

## Основные функции

- получение конфигурации с сервера;
- хранение config.json;
- опрос нескольких весов;
- формирование JSON;
- отправка данных на сервер;
- логирование ошибок;
- работа в системном трее;
- кроссплатформенность (Windows/Linux).
